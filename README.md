# EchoPulse – Offline Music Player

EchoPulse is a fully offline music player built with Expo and React Native.
It plays music stored locally on your device with a clean, premium UI.

## Features
- Fully offline music playback
- Mini-player with swipe gestures
- Play, pause, next, and previous controls
- Favorites and Recently Played
- Browse by Songs, Albums, Artists, and Folders
- Equalizer presets
- Theme accent customization
- Local storage only (no cloud, no accounts)
- No data collection

## Tech Stack
- React Native
- Expo
- Expo Router
- TypeScript
